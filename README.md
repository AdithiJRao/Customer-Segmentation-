# 🛍️ Customer Segmentation using K-Means Clustering

## 📌 Overview

This project groups customers into different segments based on their behavior using K-Means clustering. It helps businesses understand customer patterns and improve marketing strategies.

---

## 🎯 Objective

* Group customers based on similar characteristics
* Identify high-value and low-value customers
* Improve business decision-making

---

## 📊 Dataset

* File: Mall_Customers.csv
* Features:

  * Age
  * Annual Income
  * Spending Score

---

## ⚙️ Technologies Used

* Python
* Pandas, NumPy
* Matplotlib, Seaborn
* Scikit-learn

---

## 🔍 Methodology

1. Data preprocessing
2. Feature scaling
3. Elbow method to find optimal K
4. K-Means clustering
5. Visualization of clusters
6. Interpretation of results

---

## 📈 Output

* Customer groups (clusters)
* Visualization of segmentation
* Business insights

---

## 💡 Insights

* High income + high spending → Premium customers
* Low income + low spending → Budget customers
* Mixed groups → Moderate customers

---

## ⚠️ Limitations

* Choosing K value manually
* Sensitive to outliers

---

## 🚀 Future Scope

* Use advanced clustering (DBSCAN, Hierarchical)
* Real-time segmentation systems
